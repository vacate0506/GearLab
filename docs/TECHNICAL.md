# GearLab 技术说明

## 1. 技术栈

- Windows Forms（.NET Framework 4.8）承载窗口与输入。
- 界面全部使用 GDI+ 自绘，不依赖 WebView、Electron 或第三方 UI 框架。
- 相机模板与示例照片作为 `EmbeddedResource` 嵌入 exe。
- 构建使用系统编译器 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，无 NuGet、无外部 DLL。

## 3. 画布几何

导出时以目标宽度为基准，上下两个区域平分画布高度：

```text
W = 目标宽度
photoAspect = photo.Width / photo.Height
band = round(W / photoAspect)          // 完整照片在 W 宽度下的高度
H = band × 2
topH = band
photoRect = (0, band, W, band)
```

- 照片区始终显示完整原图，不裁切、不拉伸，也不额外加白边。
- 相机区固定为与照片区相同的高度；**隐藏标题不会改变 band 或上下 1:1 关系**。
- 相机与标题作为一组在上方区域内垂直居中；标题字号 `W × 0.0335`，副标题 `W × 0.012`。
- `cameraScale` 表示相机宽度占画布宽度的比例，默认 0.50，范围 0.34–0.72；如果相机内容超过相机区高度，会等比缩小机身以适配标题和边距。
- 上半幅先填充 `Style.TopColor`，再把透明底相机与标题绘制上去；标题/副标题颜色根据背景亮度自动切为深色或浅色。
- 极端长图总高度超过 12000 px 时，会等比降低宽度，仍保持上下 1:1 与完整照片比例。

## 4. 相机屏幕合成

11 个模板全部是透明底 PNG，使用归一化屏幕矩形（相对于裁切后的素材）：

| 模板 | 素材尺寸 | 归一化屏幕矩形 `x, y, w, h` |
|---|---|---|
| Ricoh GR IV | 855 × 502 | `0.035088, 0.137450, 0.676023, 0.784861` |
| Fujifilm X100VI | 632 × 362 | `0.1076, 0.3011, 0.5301, 0.6215` |
| Fujifilm X-M5 | 632 × 367 | `0.1677, 0.2343, 0.6044, 0.6894` |
| Nikon Z5II | 678 × 494 | `0.1327, 0.4251, 0.5383, 0.5020` |
| Nikon Z6III | 678 × 481 | `0.1490, 0.4595, 0.4985, 0.4449` |
| Nikon Z8 | 586 × 459 | `0.0734, 0.4227, 0.5973, 0.5054` |
| Nikon ZR | 678 × 435 | `0.1372, 0.1563, 0.6460, 0.7379` |
| Sony α7C II | 518 × 290 | `0.1795, 0.3552, 0.4517, 0.5448` |
| Sony α7C II（银） | 632 × 353 | `0.1804, 0.3569, 0.4525, 0.5382` |
| Lumix S9 | 624 × 359 | `0.1827, 0.3593, 0.4679, 0.5432` |
| Lumix S9（银） | 1704 × 981 | `0.1837, 0.3588, 0.4654, 0.5423` |

绘制顺序：

1. 按目标比例绘制透明底机身 PNG，并在下方绘制柔和投影。
2. 计算屏幕矩形，先填黑色遮住模板自带的黑色屏幕。
3. 按「填充 / 完整」把当前照片绘制到屏幕区域并裁剪。
4. 叠加很轻的玻璃高光与暗角；该选项默认关闭，只有开启时才绘制。

屏幕合成不额外截图，直接进入导出位图，因此屏幕上的照片与成片是同一张源图。相机区的背景色由 `Style.TopColor` 决定，与相机素材完全分离，所以修改背景色不会产生白边。

### 全局同步与逐张设置

- `StyleSettings` 包含五个用户可见组：相机模板、标题与文字、版面（相机大小）、相机背景、相机屏幕（显示方式/反光）。
- 每张 `PhotoItem` 保存一份完整的 `Style` 快照；`SyncAllPhotos` 默认 `true`。
- 同步开启时，`ApplyStyleChange` 把当前 `Style` 克隆到所有照片；因此上述五组修改都会作用于全部照片。
- 关闭同步后，`ApplyStyleChange` 只写回当前照片；`SelectPhoto` 会把该照片的快照载入 `Style` 并刷新检查器，实现逐张不同的设置。
- `SetSyncAllPhotos` 重新开启时，用当前设置覆盖全部照片。
- `BatchExporter.Run(paths, styles, ...)` 按索引传入每张照片的完整 `StyleSettings`，逐张渲染和命名，因此关闭同步时标题、版面、背景和屏幕也能各自不同。

## 5. DPI 与自绘

`Ui.Scale = DeviceDpi / 96`。自定义控件在 `OnPaint` 中先把 Graphics 按 Scale 变换，再以 96 DPI 的逻辑坐标绘制；子控件边界和 TextBox 字体按物理像素设置。窗口初始逻辑尺寸 1480 × 980，按工作区收缩，最小逻辑尺寸 1120 × 720。

## 6. 照片输入

- `Image.FromFile` 读取后复制为无锁位图，随后释放文件句柄。
- 读取 EXIF `0x0112` 方向，应用 8 种翻转/旋转。
- 缩略图长边 520 px；当前照片长边最大 2600 px；导出时按输出宽度加载更长边。
- 显示和导出都使用 24/32bpp 位图，不依赖 GDI+ 的缩略图缓存。

## 7. 导出

- 导出范围：当前单张 / 已勾选照片。照片库每张缩略图右上角有批量勾选框，默认全选。
- 每张照片有自己的完整设置快照；批量导出把 `PhotoItem.Style` 逐张传给 `BatchExporter`，文件名为 `GearLab_序号_源文件名_机型`。
- 底部「导出当前」和「批量导出 N」分别打开对应范围的导出面板；面板内也可以切换范围。
- 上半幅背景色由 `--bg "#RRGGBB"`（GUI 的色板 / 取色器）写入 `ExportSettings.Style.TopColor`，和照片一起进入渲染。
- 宽度 1080 / 1440 / 2160 px，**默认 2160（超清）**；高度 = 2 × 该照片在目标宽度下的完整高度，批量时不同照片高度可以不同。
- JPG 画质 60–100，默认 100（最高质量、最低压缩）；PNG 无损。文件命名 `GearLab_序号_源文件名_机型.jpg`。
- 同名文件自动追加 `_2`、`_3`，不覆盖已有文件；默认输出到程序目录的 `exports/`，不可写时回退到 `图片/GearLab`。
- `BackgroundWorker` 在后台逐张渲染与保存；进度条、状态文本、取消均可用。
- 当前渲染在 UI 线程（45 ms 合并定时器），批量导出在后台线程；相机素材通过锁缓存加载。

## 8. 相机素材来源与制作

- 11 款模板来自 `D:\ai_img` 下的模板照片；统一转为真正的 PNG（原文件夹中部分 `.png` 实际是 WebP/索引色）。
- 三张白底图片（X100VI、X-M5、α7C II 银）使用边界连通的近白像素填充抠底；其余素材本身带 alpha，直接读取 alpha bbox。
- 所有素材按内容 bbox 裁切并保留 1.8% 边距；屏幕框同步换算成裁切后的归一化坐标。逐款用样片检查屏幕覆盖，另以纯色图抽查对齐。
- 原图不再打包，只有透明底 PNG 嵌入 exe；`assets/cameras/manifest.json` 保留素材尺寸与屏幕归一化数据，便于后续增加模板。

```powershell
cd windows
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

验证覆盖：

- Windows 11（2560 × 1440，96 DPI）下启动、导入示例、11 款模板切换、横向模板条、相机大小、屏幕模式、自定义标题、背景色板 / 取色器、导出对话框、批量导出、Toast。
- 1080/1440/2160 宽度；JPG/PNG；横图 / 3:4 竖图 / 1:1 方图；填充 / 完整屏幕；默认无反光。
- 默认值为：相机大小 50%、导出宽度 2160、JPG 画质 100。
- 验证输出：4 张 3:2 示例在 1080 宽下生成 1080×1440；另用 3:4 竖图与 1:1 方图验证 1080×2880 / 1080×2160，上下等高、照片完整、无白边。
- 11 款素材逐张以样片渲染，确认屏幕矩形覆盖 LCD，不压到按键；另以纯色图抽查屏幕对齐，并在米色 / 深灰背景上检查抠图边缘。
- 关闭标题后重新渲染，高度不变，确认顶部不会缩短、上下仍为 1:1。
- 「同步全部」默认开启：修改相机/标题/版面/背景/屏幕后，所有照片的设置一并更新。
- 关闭「同步全部」后，只修改第二张照片的机身与背景；切回第一张再切回第二张，检查器恢复各自设置。
- 关闭同步后批量导出两张不同设置的照片，确认文件名、相机、标题和背景分别来自各自快照。
- 勾选 3/4 张照片后使用「批量导出 3」，实际只生成勾选照片的 3 个文件；「导出当前」生成 1 个文件。
- 1180 × 760 最小尺寸附近，照片库与设置面板可滚动；模板列表可横向滚动。
- CLI 的 `--demo`（11 款）、单文件、批量、`--glare`、`--bg`、`--quality` 参数；默认 2160 宽 / 100 画质。

## 10. 已知边界

- GDI+ 在 Windows 上不具备 HEIC/HEIF 和 WebP 解码器。
- 不支持用户导入自定义相机模板并自动识别屏幕；新增模板需要同步维护 alpha bbox 与归一化屏幕矩形。
- 模板照片本身的分辨率有限（部分 718–800 px），在 2160 px 导出时会经过插值放大；建议使用 1080/1440 导出以保持清晰。
- 为了完整显示照片并保持上下 1:1，成品总高度由原图高度推导，不锁定固定社交比例。
- 深色背景上的黑色机身对比度会降低，属于用户可选配色。
- 导出为单线程顺序任务；没有 GPU 加速。
