GearLab 器材研究所 1.3.2
============================

把照片，装进相机里。

GearLab 是一个 Windows 本地排版工具：选择相机模板，导入照片，相机屏幕显示
照片缩略图，生成一张「器材 + 成片」的分享图。相机与标题占上半幅，照片按原图
比例完整展开在下半幅；上下严格 1:1，照片不裁切、不留白边。
本版内置 11 款相机模板，上半幅背景颜色可以自定义。

■ 运行
  1. 解压整个文件夹，不要只拖出 exe。
  2. 双击 GearLab.exe。
  3. 点「导入照片」，或点「载入示例」先体验。示例会载入 4 张照片。
  4. 选择相机模板（右侧单行列表，用 ‹ › 或鼠标滚轮切换），调整相机大小、
     标题与屏幕显示。右上角「同步全部」默认开启：相机模板、标题与文字、
     版面、相机背景、相机屏幕的修改会应用到所有照片。
     关闭「同步全部」后，这些设置只影响当前照片，切换照片会恢复各自设置。
     相机大小默认 50%。
     上方相机区与下方照片区严格各占一半；隐藏标题也不会改变上下 1:1。
     照片按原图比例完整展开，不裁切。屏幕玻璃反光默认关闭。
  5. 相机背景：在「相机背景」里点 8 个预设色板之一，或点右侧十六进制色块
     打开系统取色器。只影响上半幅，标题会自动变成深色或浅色。
  6. 导出：
     · 单个导出：点「导出当前」，只导出当前照片。
     · 批量选择导出：先点各照片缩略图右上角勾选框，再点「批量导出 N」，
       只导出勾选的照片；每张照片使用各自保存的完整设置。
       也可以点顶部「导出作品」后，在面板里切换范围。

  要求：Windows 10 / 11，系统自带 .NET Framework 4.8。
  程序无代码签名；如遇 SmartScreen，请选择「更多信息 → 仍要运行」。

■ 快捷键
  Ctrl + O        导入照片
  Ctrl + E / S    导出
  Del             从照片库移除当前照片（不会删除原图）
  左 / 右方向键    切换照片
  F11             最大化 / 还原

■ 支持的图片
  JPG / JPEG / PNG / BMP / TIF / TIFF
  Windows 自带解码器不支持 HEIC / WebP，请先转换格式。

■ 输出
  照片：按原图比例完整显示，不裁切、不留白边
  版面：相机区与照片区上下严格 1:1；总高度 = 2 × 完整照片高度
  背景：上半幅支持预设色板 + 系统取色器
  宽度：1080 / 1440 / 2160 px，默认 2160（超清）
  范围：当前单张 / 已勾选照片
  格式：JPG（默认画质 100，可调 60-100）或 PNG
  默认目录：程序文件夹\exports（不可写时回退到 图片/GearLab）

■ 命令行
  GearLabCLI.exe --help
  GearLabCLI.exe --list-cameras
  GearLabCLI.exe --demo --out ".\GearLab-demo" --width 1440
  GearLabCLI.exe --input "D:\照片\dsc-2492-sea.jpg" --out "D:\导出" --camera nikon-z8 --bg "#E7E2D8"

■ 隐私
  所有处理都在本机完成；不联网、不上传照片、不需要账号。
  原图只读，程序只写入选定的导出目录。
